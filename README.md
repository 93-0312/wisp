# WISP

> 말은 연기처럼, 흔적 없이.

소규모(최대 10명) 익명 채팅 공간. 랜덤 동물 캐릭터로 2D 방을 돌아다니며 말하면,
말풍선이 몇 초 뒤 글자 단위로 흩날려 사라진다.

- **익명**: 가입/로그인 없음. 입장할 때마다 랜덤 닉네임 + 캐릭터
- **무기록**: 서버는 메시지를 전달만 하고 DB·파일·로그에 저장하지 않음. 새로고침하면 아무것도 남지 않음
- **공간**: 클릭 또는 방향키/WASD로 이동, 다른 사람의 움직임이 실시간으로 보임

## 조작

| 키 | 동작 |
|---|---|
| 클릭 / 방향키 / WASD | 이동 |
| Enter | 말하기 (7초 뒤 글자가 흩날려 사라짐) |
| Shift+Enter | 글자를 연기에 섞어 뿜기 |
| Space 길게 눌렀다 떼기 | 💨 연기 고리 (오래 누를수록 크게) |
| 1 | 😮‍💨 한숨 |
| 2 | 🫧 비눗방울 (누구나 클릭해서 터뜨릴 수 있음) |
| 3 | ✈️ 종이비행기 귓속말 (받는 사람만 내용이 보임) |
| 4 | ☕ 커피 홀짝 |
| 5 | 👉 가까운 사람 쿡 찌르기 |
| 6 | 🪴 소품으로 변신 (다시 누르면 해제) |
| 7 | 🍸 바에서 주문 (멀리 있으면 바까지 걸어감 → 메뉴판에서 1~5로 선택) |
| 8 | 🍶 홀짝 (한 잔에 네 모금, 마실수록 취함) |
| 9 | 🥂 건배 (근처에 잔 든 사람들과 짠) |
| 0 | 🎁 한 잔 쏘기 (술 고르고 받을 사람 클릭 → 잔이 미끄러져 감) |
| Alt+S | 몰래 모드 |
| Esc 두 번 | 가림막 |

숫자키와 Space는 입력창이 비어 있을 때만 동작한다. 1분간 가만히 있으면 💤 졸고, 누가 들어오면 다들 그쪽으로 고개를 돌린다.

공간은 2.5D이고 두 곳으로 나뉜다. 처음엔 아무것도 없는 **광장**에 들어오고, 뒤쪽 문으로 걸어가면 **술집**으로 들어간다.
술집 왼쪽 아래 "나가기" 매트를 밟으면 광장으로 돌아온다. 대화와 액션은 같은 공간에 있는 사람에게만 보인다.
술 주문(7)은 술집에서만 되고, 스툴이나 테이블 의자 근처에서 멈추면 자동으로 앉는다.
취하면 볼이 빨개지고, 비틀비틀 걷고, 말풍선 글자가 흔들리고, 가끔 딸꾹질을 한다. 5분 정도면 깬다.

## 실행

```bash
npm install
npm start
```

http://localhost:3000 접속. 같은 와이파이의 다른 기기는 `http://<내 PC IP>:3000`.

## 구조

```
wisp/
├─ server.js          # Express + Socket.IO, 접속자 위치만 메모리에 보관
└─ public/
   ├─ index.html      # 입장 화면 + 채팅 공간
   ├─ style.css
   └─ client.js       # 이동, 말풍선, 흩날림 효과
```

## 설정값

| 위치 | 값 | 설명 |
|---|---|---|
| `server.js` `MAX_USERS` | 10 | 최대 동시 접속 |
| `server.js` `MAX_MSG_LEN` | 200 | 메시지 길이 제한 |
| `public/client.js` `BUBBLE_MS` | 7000 | 말풍선이 흩어지기까지 시간(ms) |

## 무료 배포 (Render)

1. 이 폴더를 GitHub 저장소로 올린다
2. render.com → New → Web Service → 저장소 연결
3. Build: `npm install`, Start: `npm start`, Instance: Free
4. 생성된 `https://xxx.onrender.com` 링크 공유

무료 플랜은 15분간 접속이 없으면 잠들고, 첫 접속 시 30초 정도 깨어나는 시간이 걸린다.

## 참고

대화 내용은 서버에 남지 않지만, 호스팅 업체의 접속 로그(IP 등)나 화면 캡처까지 막을 수는 없다.
